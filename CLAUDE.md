## Monorepo Structure

This is a **pnpm + Turborepo** monorepo with two apps and five packages:

- `apps/web` — React 19 SPA (Vite, TanStack Router, Tailwind CSS v4, AI SDK)
- `apps/server` — Express 5 API server (Node.js, AI SDK, Google Gemini)
- `apps/ai-services` — FastAPI + LangGraph worker, Redis job consumer, and gRPC `ai.v1.AiService` (Python)
- `packages/db` — Prisma client with PostgreSQL (via Docker Compose)
- `packages/env` — Type-safe env validation via `@t3-oss/env-core` (separate `server` and `web` exports)
- `packages/ui` — Shared React component library (shadcn, Base UI, Tailwind)
- `packages/config` — Shared TypeScript config (`tsconfig.base.json`)
- `packages/infra` — Cloudflare deployment via Alchemy (`alchemy/cloudflare`)

## Common Commands

All commands run from the repo root unless otherwise noted.

```bash
pnpm dev               # Start all apps in parallel
pnpm dev:web           # Start web only (port 3001)
pnpm dev:server        # Start server only (port 3000)
pnpm build             # Build all packages
pnpm check-types       # Type-check all packages
```

**Database (requires Docker):**
```bash
pnpm db:start          # Start PostgreSQL via Docker Compose
pnpm db:push           # Push schema changes (no migration file)
pnpm db:generate       # Regenerate Prisma client
pnpm db:migrate        # Run migrations (creates migration files)
pnpm db:studio         # Open Prisma Studio
pnpm db:stop           # Stop containers
pnpm db:down           # Stop and remove containers
```

**Deployment:**
```bash
pnpm deploy            # Deploy via Alchemy to Cloudflare
pnpm destroy           # Tear down Cloudflare deployment
```

**Run a single app's script directly:**
```bash
pnpm turbo -F web <script>
pnpm turbo -F server <script>
pnpm turbo -F @servexa-warranty-ai/db <script>
```

## Environment Variables

Server (`apps/server/.env`):
- `DATABASE_URL` — PostgreSQL connection string
- `CORS_ORIGIN` — Allowed origin URL (e.g. `http://localhost:3001`)
- `NODE_ENV` — `development` | `production` | `test`

Web (`apps/web/.env`):
- `VITE_SERVER_URL` — URL of the Express server (e.g. `http://localhost:3000`)

Env validation is in `packages/env/src/server.ts` and `packages/env/src/web.ts`. Both use `@t3-oss/env-core` with Zod schemas and will throw at startup if required vars are missing.

## Architecture

### AI runtime policy
See [documents/ai-runtime-policy.md](documents/ai-runtime-policy.md) for runtime ownership (Node vs Python), sync/async job rules, memory stance, and canonical RAG corpus (Prisma `ai_knowledge_*`).

### Data Flow
Web (`useChat` via `@ai-sdk/react`) → POST `{SERVER_URL}/ai` → Express server → Google Gemini (`gemini-2.5-flash`) → streaming response back to browser.

The server uses `streamText` from the AI SDK and pipes a UI message stream directly to the HTTP response via `result.pipeUIMessageStreamToResponse(res)`.

### Routing
`apps/web` uses **TanStack Router** with file-based routes in `src/routes/`. The route tree is auto-generated at `src/routeTree.gen.ts` — do not edit this file manually. Add new routes by creating files in `src/routes/`.

### UI Components
`packages/ui` exports shadcn-style components at `@servexa-warranty-ai/ui/components/*`. The package uses Base UI primitives. Add new shadcn components by running `shadcn add <component>` from `packages/ui`.

### Database
Prisma schema is in `packages/db/prisma/schema/schema.prisma`. The generated client outputs to `packages/db/prisma/generated/`. The client is created via `createPrismaClient()` using the `@prisma/adapter-pg` driver (not the default Prisma engine). Import the singleton: `import prisma from "@servexa-warranty-ai/db"`.

### Infrastructure
`packages/infra/alchemy.run.ts` deploys `apps/web` as a Cloudflare Worker (Vite asset serving). The Alchemy config reads `.env` from the infra package and `../../apps/web/.env`.
